## Wavelet CT（小波 CT）

### 观察 (Observation)

- 在采样过程中，扩散模型倾向于**先生成低频信息，再生成高频信息**
- 换句话说，**高频信息依赖于低频信息**。小的物件 / 细节纹理，长在大的物件上面。

### 问题 (Question)

- 我们能否利用这个观察，去**增强 few-step 方法（CT**）的性能**？

### 方法 (Method)

将图像 $x $ 分解为一系列经过小波变换的层（layer）：

| 层      | 分辨率 | 含义                               |
| ------- | ------ | ---------------------------------- |
| Layer 0 | 4×4    | 全局平均图（global average image） |
| Layer 1 | 8×8    | 残差图（residual image）           |
| Layer 2 | 16×16  | 残差图                             |
| Layer 3 | 32×32  | 残差图                             |

在生成器（generator）网络中，**让高频层的生成以低频层的输出作为条件**：

- **Layer 0**：4×4，不依赖任何其他层
- **Layer 1**：8×8，以 layer 0 为条件
- **Layer 2**：16×16，以 layer 0 + layer 1 为条件
- **Layer 3**：32×32，以 layer 0 + layer 1 + layer 2 为条件

**最终生成的图像 $x_0' $ = (4×4 $x_0' $) + (8×8 $r_0' $) + (16×16 $r_0' $) + (32×32 $r_0' $)** （即各层上采样后相加）

### 监督方式 (Supervision approaches)

**两种可选方案：**

1. **Sum supervision（求和监督）**：只在最终求和后的 $x_0' $ 上施加监督
2. **Residual supervision（残差监督，teacher forcing）**：
   - 在 4×4 $x_0' $、8×8 $r_0' $、16×16 $r_0' $、32×32 $r_0' $ 上**分别**施加监督
   - 用目标图像经过小波变换得到的各层作为 ground truth

### 第一张图（Method 部分）解读

展示了**小波分解**的过程：从原图 32×32 出发，逐级下采样得到 16×16、8×8、4×4，每相邻两层之间的差就是该尺度的"残差 r"。也就是：

- $r_{32×32} $ = 32×32 原图 − 上采样的 16×16
- $r_{16×16} $ = 16×16 − 上采样的 8×8
- $r_{8×8} $ = 8×8 − 上采样的 4×4
- 4×4 = 全局平均

### 第二张图（Generator structure）解读

展示了**生成器的级联结构**：

- 4 个 network 分别负责 4 个分辨率
- 输入是各分辨率的 $r_t $（加噪后的残差），输出是预测的 $r_0' $
- **低分辨率的输出会作为高分辨率 network 的条件**（图中向上的箭头）
- 每个分辨率都接一个 supervision，可以是 residual supervision 也可以是 sum supervision

------

### 整个 idea 的中文一句话总结

> "扩散模型采样是从粗到细的，那我就**显式地把图像拆成多个分辨率层**，让模型**一层一层从粗到细地生成**，并且**每一层都加上独立的监督信号**——看看这样能不能让 CT 这种 few-step 方法生成质量更好。"
